The dataset contains information on subway lines, stations, and station
entrances. Variables include `line`, `station_name`, `station_latitude`,
`station_longitude`, routes served (`route1` to `route11`), `entry`
(whether the entrance allows entry into the station), `vending` (vending
machine availability), `entrance_type`, as well as `ada` (ADA
compliance). For data cleaning, I first cleaned the variable names by
using `clean_names` function, then selected the variables needed for the
analysis by using `select` function, and finally converting `entry` from
a character variable to a logical variable by applying `mutate` and
`case_match` functions. The resulting dataset has 1868 rows and 19
columns. These data are not tidy because information on routes served
are stored in multiple columns instead of in separate route number and
route name variables.

**Reformat data**

``` r
nycsubway_df = 
  nycsubway_df |> 
  mutate(
    across(route1:route11, as.character)
  )

nycsubway_tidy_df = 
  nycsubway_df |>
  pivot_longer(
    route1:route11, 
    names_to = "route_number", 
    names_prefix = "route", 
    values_to = "route_name", 
    values_drop_na = TRUE
  )

# Number of distinct stations that serve the A train
nycsubway_tidy_df |>
  filter(route_name == "A") |>
  distinct(line, station_name) |> 
  nrow()
```

    ## [1] 60

``` r
# Of the stations that serve the A train, how many are ADA compliant?
nycsubway_tidy_df |>
  filter(
    route_name == "A", 
    ada == TRUE) |>
  distinct(line, station_name) |> 
  nrow()
```

    ## [1] 17

There are 60 distinct stations that serve the A train. Of the stations
that serve the A train, 17 are APA compliant.
